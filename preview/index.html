P1001 A+B Problem

洛谷 · 菲林斯主题预览

入门 模拟 数学 洛谷原创

题目描述

输入两个整数 a、b，输出它们的和（|a|,|b| ≤ 109）。

注意：Pascal 使用整数时，会得到 Wrong Answer，请改用 longint。

输入格式

两个用空格隔开的整数。

输出格式

一个整数，表示 a + b 的值。

提示：评测机会忽略每行末尾的空格与最后一行的换行符，请不要输出多于答案的内容。

输入输出样例

输入 #1
1 2
输出 #1
3

说明 / 提示

数据规模取值范围建议做法
小数据|a|,|b| ≤ 103直接相加
大数据|a|,|b| ≤ 109注意使用 64 位整数

参考实现：

// 「灯就是用来照亮黑暗的，不是吗？」
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}
